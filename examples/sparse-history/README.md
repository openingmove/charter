# Sparse example: local history papers

This README is not part of the papers: leave it out of Migrate and out of its completeness list.

A small historical society's loose papers: three long prose documents (`town-history.md`, `oral-histories.md`, `walking-tour.md`) that mix people, places and events, and an `archive/` folder of old committee minutes. No frontmatter, no `charter.yaml`.

## Walkthrough

- **Ignore this README** in every step below; it describes the example, it is not a document to migrate. The draft contract ignores it with `"README.md": {ignore: true}`.
- **Establish** (on a copy of this folder): the survey shows a sparse folder, and the interview about the society's domain should propose kinds such as person, place and event. It then asks, per kind and in your words, whether its notes share a fixed outline (for example, whether every story of the town has the same sections). The papers are loose prose, so the headings of a template it writes, such as `Templates/Story.md`, are optional; it shows you the template as a sample note beside `charter describe --config <draft>`, waits while you read it and edit the file if you wish, and reruns the description to catch an edit that stops the contract loading. A kind you answer "no template" for stays valid and `charter new` still works for it. The walkthrough ends with at least one template. The papers carry no frontmatter, so they do not fit the draft contract. Establish therefore installs nothing: it leaves `charter.draft.yaml`, the template files and a migration plan, `charter.migration-plan.md`, in the folder (the plan lists the templates; Migrate's clean-state check treats them as Establish's own files), with `archive/` marked `leave as it is` (path policies `untyped: allow` and `edit: read-only`), and tells you to run `/charter:migrate`.
- **Migrate**: it first makes a way back. Under git it asks for a clean tree and offers a new branch; without git it takes a `charter snapshot`. It then agrees the section map with you, splits each document into one note per person, place and event, keeping every paragraph's content, and installs the contract. The walkthrough succeeds when `charter validate --all` is clean (`archive/` is read-only and Migrate never touches it, and any source it keeps becomes read-only too, with `untyped: allow` plus `edit: read-only` in the draft, so there are no edit-policy findings) and the completeness check of each original finds no paragraph missing from the new notes.
- To run it again, use the undo Migrate stated at the end: switch back to the starting branch, or restore the snapshot.
